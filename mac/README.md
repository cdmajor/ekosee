# Mac / Safari

Safari packaging lives in **`safari/`** and **`downloads/ekosee-safari.zip`**.

```bash
# rebuild
./scripts/package-extensions.sh

# on a Mac, from the safari package:
cd safari && ./convert-for-safari.sh
```

See [`safari/README.md`](../safari/README.md) and [`downloads/README.md`](../downloads/README.md).
